# Cybersecurity Projects

Collection of hands-on cybersecurity projects focused on network traffic analysis, SIEM investigations, threat detection, and host exposure analysis.

## Projects

### Malware Traffic Analysis and C2 Detection with Wireshark
- Analyzed malicious PCAP traffic using Wireshark
- Identified beaconing behavior and command-and-control (C2) communication
- Investigated suspicious HTTP POST requests, User-Agent strings, and encoded payloads

### SSH Brute Force Detection and Log Analysis in Splunk
- Investigated SSH authentication logs using Splunk Enterprise
- Detected brute-force behavior using SPL queries and alerts
- Created visualizations and dashboards for authentication monitoring

### Windows Host Exposure Analysis using Nmap
- Performed advanced and full TCP port scans on a Windows host
- Identified exposed services and potential attack vectors
- Analyzed SMB and RPC-related security risks
